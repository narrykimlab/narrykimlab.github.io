{%- comment -%} An email address as a button (.chip), out of address harvesters' reach. The address is drawn, not written: the HTML holds code points of Unicode's Private Use Area (the mail_glyphs filter, _plugins/mail_glyphs.rb), which the font NKL Mail Display draws as the address in Montserrat's own glyphs, and which mean nothing to a program reading the page, even one that runs its scripts. js/site.js makes it a mailto link that holds the address only while someone points at it, focuses it or clicks it, and copying it copies the address. Screen readers hear "Email " rather than characters that mean nothing to them. Without scripts it stays a box showing the address.
